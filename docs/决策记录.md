# 决策记录（Pek.RWindows）

## 2026-10-27 立项：Windows 11 搜索失灵替代工具

### 用户原话（需求）

> 目前Windows11左下角的搜索经常用不了，导致想搜某个应用都搜索不出来。是否能帮我用Rust实现一个简单好用的小工具。这个工具要能自动缩小到右下角盘中，而且要能搜索出当前电脑上安装过的应用。这样才好在windows自带的不能用时可以替换使用，可以借鉴联网上的开源项目

### 决策

1. **形态**：单 exe 托盘工具，无服务、无安装器；启动即藏到托盘，热键 `Alt+Space` 唤出。
2. **界面技术**：`eframe/egui`（glow）。理由：纯 Rust、无 WebView/运行时依赖、体积与上手成本可控；
   原生 Win32 自绘能达到同样效果但开发量高得多。代价：内存约 140 MB（GL 上下文为主）。
3. **应用数据源**：`shell:AppsFolder` 枚举（与开始菜单同一数据源，覆盖桌面程序 + UWP/商店应用），
   参照 PowerToys Run / Wox 的 UniversalApps 插件；另加开始菜单目录扫描兜底与 `ExtraScanDirs` 扩展。
   不读注册表卸载项（会混入卸载器、运行库、更新器，噪音大）。
4. **启动方式分流**：有磁盘路径（PIDL → `SHGetPathFromIDListW`）用 `ShellExecute`；
   只有 AUMID 时用 `IApplicationActivationManager`，失败退回 `explorer shell:AppsFolder\<AUMID>`。
5. **隐藏策略**：不移除窗口可见性，只把窗口移到屏幕外（-30000,-30000）。
   原因：Windows 上窗口隐藏后不再产生 `WM_PAINT`，托盘/热键线程发出的指令会「送到但界面不动」，
   这是同类工具最常见的假死来源。
6. **焦点判定**：用 Win32 `GetForegroundWindow()` 对比本进程窗口句柄，不用 egui 的 `focused` 标志
   （刚显示时会报假值，导致「一弹出就自动隐藏」）。
7. **输入法**：**不关闭 IME，支持中文输入**（2026-10-27 用户反馈后修正：初版为“回车不被候选框吞掉”关闭了
   IME，导致中文没法输入）。中文输入法选词时第一个回车用于上屏（与普通输入框一致），上屏后再回车启动；
   只用拼音/英文时无需切输入法。拼音（全拼 + 首字母）仍是快速路径。
8. **图标**：文件类用 `SHGetFileInfoW`（快），打包应用用 `IShellItemImageFactory`（慢但准确）；
   列表与图标分离：列表 ~0.35s 可用，图标后台分批补（实测 1.7~2.3s 完成）。
9. **并发/资源**：无轮询、无定时器；隐藏空闲 0 CPU。托盘线程阻塞在 `GetMessageW`，事件走回调。
10. **配置**：`Config/Settings.toml`，统一走 `dhrust::config::TomlConfig`（模板生成/缺键补齐/损坏重建），
    不另写迁移与模板逻辑；热键修改重启生效（避免运行时重注册的边界问题）。
11. **单实例**：命名互斥体 + 命名事件；重复启动会唤醒已运行实例，不弹第二个窗口。
12. **体积（2026-10-27 用户反馈「打包出来好几M」后修正）**：
    - 关闭 eframe 默认特性（`accesskit`、`winit/default`、`web_screen_reader`、`wayland/x11` 等），只留 `glow`；
    - 不再打包 egui 内置字体（1.37MB 源数据），改为启动时加载系统字体（微软雅黑/Segoe UI 等）；
    - `[profile.release]` 用 `opt-level="z"` + fat LTO + `codegen-units=1` + `strip` + `panic="abort"`。
    - 结果：release exe 6.63 MB → **2.99 MB**，zip 2.76 MB → **约 1.1 MB**。

### 未做（后续可开）

- 文件/文件夹搜索（Everything 风格索引）：与本工具「应用搜索」定位分离，避免常驻索引开销。
- 插件/自定义命令（PowerToys Run 的 `>` 前缀类能力）。
- 图标磁盘缓存（当前每次启动重新提取，约 2s 后台完成）。
- 安装包（MSI/Inno Setup）与自动更新：当前以绿色 zip 交付 + 托盘「开机自启」开关。
