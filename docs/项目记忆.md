# 项目记忆（Pek.RWindows）

> 每轮收尾由 AI 更新；内容为「下次接手必须知道」的事实，而非流水账。

## 项目定位

- 路径 `G:\Code\Rust\Pek.RWindows`，crate `pek-rwindows`（单 bin，Windows 桌面工具）。
- 目标：Windows 11 自带搜索失灵时的替代品——托盘常驻、热键唤出、搜已安装应用、可拼音。
- 远程：待建（本轮尚无 remote）。

## 关键事实

- 技术栈：eframe/egui 0.32（glow）、`tray-icon` 0.21、`windows` 0.62、`fuzzy-matcher`、`pinyin`、`dhrust`（path 依赖，features = toml）。
- 应用数据源：`shell:AppsFolder`（IShellFolder 枚举）+ 开始菜单目录兜底 + `ExtraScanDirs`。
  - AppsFolder 条目的 `SIGDN_FILESYSPATH` 取不到；真实路径要用 **`SHGetPathFromIDListW(pidl)`**。
  - 打包应用 `FILESYSPATH` 为空、只有 AUMID；部分安装器把 AUMID 写成 exe 路径（需按路径启动）。
  - 帮助/网页条目（`{GUID}\...\x.chm`、`https://...`）必须丢弃，否则会有启动失败项。
- 图标：文件类 `SHGetFileInfoW`（32px，快）；打包应用 `IShellItemImageFactory`（慢，1.5s 级，故渐进推送）。
- 隐藏策略：**不移除窗口可见性**，只移到屏幕外（-30000,-30000）。原因：Windows 上隐藏窗口后收不到
  `WM_PAINT`，托盘/热键指令会「发出去但界面不动」。
- 焦点判断用 **Win32 `GetForegroundWindow()==own hwnd`**，不能用 egui 的 `focused`（刚显示时报假值，
  曾导致「热键唤起后一闪就没」）。
- `own_window()` 按进程 PID + 标题 `Pek 启动器` 枚举查找；**失败结果不能缓存**（标题可能在 App::new 时还没设好）。
- 搜索框每帧发 `ViewportCommand::IMEAllowed(false)`：egui-winit 会在文本框获焦时自动重新启用 IME，
  只关一次会被覆盖；关闭后回车才不会先被输入法候选框吃掉。
- 托盘线程自带 `GetMessageW` 消息泵（`WM_HOTKEY` 也在这里处理）；事件全部走 tray-icon/muda 回调，
  空闲时阻塞、零 CPU。
- 配置 `Config/Settings.toml` 用 `dhrust::config::TomlConfig`（模板生成/缺键补齐/损坏重建）。
- 日志 `Log/yyyy_MM_dd.log`（`dhrust::logs`），退出前 `flush()`。
- 单实例：命名互斥体 `Local\Pek.RWindows.Launcher` + 事件 `Local\Pek.RWindows.Show`
  （第二实例 SetEvent 唤起第一实例）。
- 启动时 `set_current_dir(exe 目录)`：注册表自启工作目录是 system32。

## 验证基线（2026-10-27）

- `cargo test`：13 项全绿；`cargo clippy --all-targets` 零告警。
- `--dump-apps` 实机：139 项；列表 333~407ms 可用；图标 1.7~2.3s 补完。
- 实机交互：热键唤起、输入 `jsq` 回车启动计算器、Esc 隐藏、Alt+Tab 失焦自动隐藏 —— 均通过。
- 隐藏空闲 5 秒 CPU 增量为 0；工作集约 144 MB。
- 发布包：`dist/PekLauncher_v0.1.1_win-x64.zip`（2,760,371 B，
  SHA256 `F5902563E29B1A2117A1AC82127D11648A7DA81F5538D4F0E63191709A67CD7E`），
  release exe 6,627,840 B（strip + fat LTO）；release 自检通过（显示→隐藏→显示→退出）。
